Quick Installation

Drop Into Any Project

Consume via standard CSS custom properties or portable JSON tokens in React Native, Tailwind, or Figma plugins. 

<!-- 1. Include Google Fonts in <head> -->
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link href="https://fonts.googleapis.com/css2?family=Outfit:wght@400;500;600;700;800&family=Plus+Jakarta+Sans:wght@400;500;600;700&display=swap" rel="stylesheet">

<!-- 2. Link the personal brand theme -->
<link rel="stylesheet" href="brand.css">

<!-- 3. Use tokens naturally in CSS -->
<style>
  .hero-title {
    font-family: var(--font-heading); /* Outfit */
    color: var(--color-primary);      /* Teal #0d9488 */
  }
  .body-copy {
    font-family: var(--font-family);  /* Plus Jakarta Sans */
    font-size: var(--base-font-size); /* 16px */
  }
</style>
